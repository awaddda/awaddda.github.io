# Portafolio

Página que reúne mis proyectos web:

- **[Cripteando](https://awaddda.github.io/cripteando/)** — una pista críptica nueva por día.
- **[Manjares Serranos](https://awaddda.github.io/manjares-serranos/)** — sitio de una marca de embutidos de Córdoba.
- **[Turopeo](https://awaddda.github.io/turopeo/)** — landing de una agencia de viajes.

Es HTML y CSS sin dependencias. Para verla localmente, abrí `index.html` en el navegador.

## Agregar un proyecto

1. Poné una imagen de vista previa en `img/`.
2. Copiá un bloque `<article class="project">` en `index.html` y cambiá textos, links e imagen.
